# Memory Training

A collection of brain training games to sharpen your memory, attention, and cognitive skills.

## Games

### Schulte Table
Find numbers 1 through N in order, as fast as you can. A classic speed-reading exercise that develops peripheral vision. Grid sizes from 3×3 to 7×7.

### Gorbov-Schulte Table
An advanced version with two-colored numbers. Alternate between red and black numbers in ascending and descending order. Great for training attention switching.

### Memory Matrix
A grid flashes highlighted cells. Reproduce the pattern from memory. The grid grows larger as you progress.

### Repeat Pattern
Dots appear connected by lines. Memorize the connections, then draw them yourself. Each level adds more complexity.

### Find Pair
Classic card matching. Flip two cards at a time looking for pairs. Find all matches with the fewest moves.

### N-Back
A cell lights up on a grid. Decide if the current position matches the one N steps ago. Adjustable difficulty (2-back, 3-back, etc.).

### Sequence Memory
Cells light up one by one. Repeat the sequence by tapping cells in the same order. Each round adds one more step.

### Chimp Test
Numbers appear briefly, then hide. Tap them in order: 1, 2, 3... Tests short-term visual memory and quick recall.

### Picture Memory
Images appear one at a time. For each image, decide: have you seen it before, or is it new? Three mistakes and you're out.

### Object Location
Icons are placed on a grid. Memorize their positions. After they vanish, put each icon back where it was.
